# Calendar Local 배포

로그인 없이 폴더째 들고 다니는 Windows 포터블 캘린더의 배포 파일만 있는 저장소입니다.

## 받기

[최신 버전 받기](https://github.com/jjong0203-pixel/Calendar_Local-Releases/releases/latest) → `Calendar_Local_…_Portable_Windows_x64.exe`

- 원하는 폴더에 두고 실행하면 같은 폴더에 `Data`가 생기고 거기에 일정이 저장됩니다.
- 0.4.3부터는 앱을 켤 때 새 버전을 알려 주고, 누르면 EXE만 바꿔 다시 켭니다(Data는 그대로).
- 다른 PC나 USB로 옮길 때는 EXE와 `Data`를 함께 옮깁니다.

## 이 저장소

- `channels/stable.json`: 앱이 확인하는 업데이트 목록(서명됨). 앱은 서명이 맞는 목록만 믿습니다.
- 소스는 이곳에 없습니다.
